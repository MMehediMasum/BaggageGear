## Common Issues And Solutions

![](https://tse1.mm.bing.net/th?q=using-the-united-bag-drop-shortcut-can-save-time,-but-some-issues-may-arise.-understanding-common-problems-helps-travelers-fix-them-quickly.&w=424&h=324&c=7)

Using the United Bag Drop Shortcut can save time, but some issues may arise. Understanding common problems helps travelers fix them quickly. This section highlights typical challenges and clear solutions.

### Technical Glitches With The Bag Drop Kiosk

Sometimes, the kiosk may freeze or not respond. Restart the machine if possible. Check your internet connection, as it can affect the system. Clear the screen by tapping 'Cancel' and start again. If problems continue, seek help from airport staff nearby.

### Problems Scanning Your Boarding Pass

Errors scanning a boarding pass are common. Ensure the barcode is clean and not damaged. Hold your phone or paper steady in front of the scanner. Try adjusting the angle or brightness if using a phone screen. Print a physical boarding pass if scanning fails repeatedly.

### Issues Printing Bag Tags

Sometimes, bag tags don’t print properly. Check if the printer has paper and ink. Make sure the tag is fully inserted in the slot. Wait a few seconds for the printer to finish. If the tag is missing or smudged, ask for assistance at the counter.

### Difficulty Attaching Bag Tags

Attaching bag tags can be tricky for some users. Use the provided fastener or loop to secure the tag. Avoid placing the tag where it can fall off easily. Double-check the tag is firmly attached before dropping the bag. Ask for help if unsure about attachment.

### Unexpected Charges Or Weight Errors

The system may show weight errors or extra fees. Remove heavy items from your bag and weigh again. Confirm that your bag meets airline size and weight limits. Weigh your bag on a separate scale if needed. Contact airline staff for clarification on charges.
